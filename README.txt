Файлы:
thread_server.c — исходный код TCP эхо-сервера (C, POSIX threads).
test_clients.py — тест трёх одновременных клиентов.
вывод_трех_клиентов.txt — фактический вывод проверки.
Эссе_многопоточность.docx — эссе на одну страницу.

Сборка (Linux):
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 -pthread thread_server.c -o thread_server

Запуск:
./thread_server 9090

Во втором терминале — проверка трёх клиентов:
python3 test_clients.py 9090

Остановка: Ctrl+C в терминале сервера.

Описание:
- Сервер слушает локальный адрес 127.0.0.1 и указанный TCP-порт (по умолчанию 9090).
- Каждый клиент обслуживается отдельным pthread-потоком.
- Сервер возвращает клиенту те же байты, которые получил (эхо).
- Общие счётчики активных и всех подключений, а также флаг завершения защищены pthread_mutex_t.
- Все сокеты закрываются; аргумент потока освобождается.
- При Ctrl+C сервер прекращает принимать подключения, даёт клиентским потокам закончить и выводит итоговую статистику.
- Таймауты recv/send позволяют завершить поток, даже если клиент бездействует.
- Активного цикла опроса клиентов (busy-loop) нет.

Результат проверки: три клиента одновременно установили соединение и получили правильное эхо. В конце работы активных подключений — 0.
